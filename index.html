YOUR THREAT INTELLIGENCE FIELD GUIDE

Know what to look for.

Signal turns CISA’s Known Exploited Vulnerabilities catalog into a practical watchlist, so security teams can quickly find vulnerabilities attackers are known to exploit and decide what to investigate first.

QUICK REFERENCE

What the fields mean

Definitions for the dashboard cards and watchlist.

SUMMARY

Known exploited

Total number of vulnerabilities currently listed in CISA’s KEV catalog.

SUMMARY

Added this month

Entries whose CISA “date added” falls in the current UTC calendar month.

SUMMARY

Ransomware linked

Entries CISA marks as known to be used in ransomware campaigns. “Not confirmed” does not prove it has never happened.

SUMMARY

Data freshness

Time since this browser last fetched the catalog successfully. The five-minute timer checks for source changes; it does not mean CISA publishes new entries every five minutes.

WATCHLIST

Vulnerability

The CVE identifier and vulnerability name. Select the CVE to open its record at CVE.org.

WATCHLIST

Vendor / product

The vendor and affected product named in the CISA catalog. Compare them with software you use.

WATCHLIST

Added to CISA catalog

The date CISA added the vulnerability to KEV. It is not necessarily the date the flaw was discovered.

WATCHLIST

Ransomware use

“Known” means CISA lists confirmed ransomware campaign use. “Not confirmed” means CISA has no known confirmation in this field.

WATCHLIST

Remediation due date

The due date published by CISA for remediation. Use it as a prioritization reference and check your organization’s applicable requirements.

CHART

Added over time

How many catalog entries were added on each of the last 30 days. Empty bars mean no additions on that date.

SOURCE

Feed status & release

Live means a public feed responded. Cached means the latest saved copy is shown while the feed is unavailable. Catalog release is CISA’s release date.

TOOLS

Search, filters & export

Search CVE, vendor, or product; filter by vendor; sort results; or export the matching list as a CSV file.

iHow to read this dashboardQuick guide to the counts, dates, and status⌄

Live catalog, not live sensors. The page checks CISA’s catalog every five minutes. New entries appear when CISA updates the source, usually on weekdays; this is not a real-time incident detection feed.

Due date is the remediation deadline in the CISA catalog. Ransomware linked means CISA marks known ransomware campaign use. Use CVE links and your own asset inventory to assess exposure.
